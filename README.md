# 🏆 ArenaX – College Sports Management Platform

**ArenaX** is a comprehensive college sports management platform designed to streamline sports facility slot bookings, sports equipment issuance, and overall sports inventory management within educational institutions.

## 🌟 Key Features of Project 

### 🎓 Student Portal

* **Facility & Court Booking:** Reserve time slots for campus sports facilities such as Badminton Courts, Table Tennis Courts, Swimming Pools, and more.
* **Equipment Issuance:** Request and borrow sports gear and equipment directly through the portal with clear issue and return tracking.
* **Slot Status & History:** View upcoming booking schedules and track past bookings and equipment issuance history.

### 🛡️ Admin Panel

* **Inventory Management:** Manage sports equipment stock, including adding new items, tracking availability, and marking damaged assets.
* **Booking & Issuance Approval:** Monitor and manage facility bookings and equipment checkout/check-in operations.
* **Facility Management:** Add, update, or temporarily disable facilities and slots for maintenance or official college sports events.

## 🔄 Development Workflow

The project is developed collaboratively using Git and GitHub following a standard feature-branch workflow:

```text
Feature Branch
      ↓
    Commit
      ↓
     Push
      ↓
Pull Request
      ↓
Code Review
      ↓
    Merge
      ↓
    main
```

### Workflow Steps

1. Each team member works on a designated feature branch such as:

   ```text
   feature/feature-name
   ```

2. Changes are committed regularly with meaningful commit messages.

3. Changes are pushed to the respective remote feature branch.

4. A Pull Request is created on GitHub.

5. Another team member reviews the changes.

6. After approval, the Pull Request is merged into `main`.

7. Team members should pull the latest changes from `main` before starting new work.

## 🔮 Future Scope

Future enhancements planned for ArenaX include:
